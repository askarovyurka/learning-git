\## Git Workflow и правила работы в команде



\### Роли участников:

\- Разработчик 1 - Юра

\- Разработчик 2 - Ваня

\- Разработчик 3 - Макс



\### Стратегия ветвления:

\- main — главная стабильная ветка проекта.

\- Личные ветки — черновые пространства каждого участника для длительных или экспериментальных задач.

\- Ветки фич — изолированные ветки для конкретных задач и разработки нового функционала.



\### Правила слияния (Merge):

\- Прямое сохранение (push) в ветку main запрещено.

\- Любой новый код должен добавляться исключительно через создание Pull Request.

\- Перед слиянием обязательна проверка кода (code review) вторым участником.
